# Herdr

The installed Herdr binary supplies the maintained instructions for this skill.
Run `herdr --skill` and read its output before first controlling Herdr. Follow
that guidance, including its environment check and command discovery steps.

Load the binary's instructions once per session and reuse them. Read them again
only if they are no longer in context or Herdr has been upgraded. Reading this
entrypoint alone does not count as loading the binary's instructions.

Do not keep a copied command reference here. If `herdr` or `herdr --skill` is
unavailable, report that limitation rather than guessing control commands.
