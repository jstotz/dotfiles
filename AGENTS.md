# Repository instructions

Keep `README.md` a minimal quickstart: the repository's purpose, essential setup
and apply commands, local customization, and how to run validation.

Do not add feature descriptions, keybindings, plugin documentation, dependency
inventories, or tool-specific usage guides to the README. Adding or changing a
feature, plugin, or dependency does not require a README update. Keep necessary
implementation details beside the relevant configuration or install script.
